# Egyptian National ID OCR Pipeline

An open-source, fully local ML pipeline to extract structured data from Egyptian National ID cards.

## Features
- **Offline & Local**: No cloud APIs or LLMs used.
- **Robust Detection**: Works from any angle, including A4 scans with whitespace.
- **Structured Output**: Extracted data includes names, address, NID decoding, and more.
- **REST API & CLI**: Integratable into any application.
